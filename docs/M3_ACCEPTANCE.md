## 修复记录

- **缺陷**：策略B/C 止损直接用 ma20，距离买入价可能 >4%，导致风控大量误杀
- **修复**：`stop_loss = max(ma20, close×0.96)`，统一保证止损距离 ≤4%
- **效果**：止损超标信号 11 → 4，推荐 0 → 1

### 根本原因分析（按重要性）

1. **样本太小且严重偏差**：100 只 = 深市代码前100（000001-000100），几乎全是老牌主板股（平安银行、万科等），大盘股波动小，短线策略天然难赚钱，**不能代表全市场**
2. **数据区间短**：仅 120 天，可能正好落在特定行情段
3. **持有期 5 天偏短**：A股短线噪音大，与用户「1周-3月中线」偏好不完全匹配
4. **策略本身简单**：形态策略在震荡市胜率天然偏低

### 关键判断

**当前 100 只样本的胜率数据，不能作为策略有效性的结论性判断。** 真正的胜率需要：
1. 全市场（或 ≥1000 只代表性样本）
2. 更长回测区间（1-2 年）
3. 合适的持有期（匹配用户 1周-3月）
