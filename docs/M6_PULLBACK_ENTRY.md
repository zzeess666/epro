# M6 回踩买入逻辑 — 开发任务指令

> 供 cursor-agent 执行。核心：把「信号日收盘追高买入」改为「信号日标记 → 回踩均线再买」。

## 背景

M5 诊断发现：技术信号（多头排列/金叉/穿三线）在信号日收盘买入=追高，胜率卡在 59.6%，突破不了 60%。根因是买入点太高。

## 目标

修改 `src/combo/combination_miner.py` 的回测逻辑，买入点从「信号日收盘」改为「信号日后回踩均线」。

## 回踩买入规则（核心）

1. **信号日 T**：组合内所有指标 flag=1 的日子，**只标记，不买入**
2. **回踩窗口**：T+1 到 T+5（最多等 5 个交易日）
3. **回踩日判定**（窗口内第一个满足以下全部条件的日子）：
   - 最低价 ≤ MA10（触及短期均线支撑）
   - 收盘价 > MA20（中期趋势未破坏）
   - 成交量 ≤ 信号日成交量（缩量回踩，洗盘充分）
4. **买入**：回踩日收盘价
5. **止损**：买入价 × (1 - 周期止损幅度)，维持分周期止损（超短2%/短3.5%/中短5.5%/中8%）
6. **持有**：从回踩日起 hold_days 天
7. **放弃**：若 5 天内无回踩，放弃该信号（宁可错过，不追高）

## 实现要点

- `daily_kline` 表已有 `ma10`、`ma20` 字段，直接用，无需重算
- `_simulate_periods` 需改为「先定位回踩日，再模拟持有」
- 需加载每只股票的完整 K 线序列（含 ma10/ma20/v），在信号日之后向后扫描找回踩日
- 训练/测试切分、样本门槛、组合枚举逻辑不变
- 保留防过拟合（训练80%/测试20%双验证）

## 验收标准

1. 回踩买入后，重新跑 `run_miner.py`，观察最高综合胜率是否突破 60%
2. 回踩买入逻辑正确：买入价 = 回踩日收盘（不是信号日收盘）
3. 5天无回踩的信号被正确放弃
4. 训练/测试双验证、样本≥30 门槛不变
5. 无未来函数（回踩日买入，只用回踩日及之前的数据判断回踩条件）

- ❌ 不 git commit/push（架构师验收后统一提交）
- ❌ 不用未来数据（回踩日的判断只能用当日及之前数据）
- ❌ 不调麦蕊 MA 接口（用 daily_kline 本地 ma10/ma20）
