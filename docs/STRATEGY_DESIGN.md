# EPro 策略设计文档（v2.0 重构蓝图）

> 2026-08-14 · 架构师与用户共同确认

## 核心思想：动态指标组合（自适应，非固定条件）

市场风格会变，选股逻辑不能一成不变。不预设固定买入条件，而是：
**计算大量指标 → 自动组合 → 回溯排名 → 动态用当前最优组合选股 → 定期刷新**

## 架构

```
① 因子库：每天每只股票计算指标（数量不限，0/1 标记）
② 组合挖掘：自动枚举 2-3 个指标的组合
③ 回溯排名：每个组合分 4 周期回测胜率
④ 动态选股：用当前胜率最高组合筛股
⑤ 定期刷新：每周重挖，适应风格切换
```

## 持有周期（4类）

| 周期 | 交易日 | 止损幅度 |
|------|--------|---------|
| 超短 | 1-3天 | 2% |
| 短 | 5天（1周）| 3-4% |
| 中短 | 20天（1个月）| 5-6% |
| 中 | 60天（3个月）| 8% |

## 选股范围过滤（硬规则）

1. **剔除 ST / *ST**（名称含 ST）
2. **剔除京市**（北交所，jys = BJ）
3. 仅保留沪深两市（SZ / SH）

## 因子库规划（用户指定 3 个 + 架构师补充，数量不限，不强制 20-30）

### 用户指定（必须包含）
- MACD 金叉（diff > dea）
- 跳空（跳空高开）
- 一阳穿三线（一根阳线穿越 MA5/MA10/MA20）

### 技术类（架构师补充）
- MA5>MA10>MA20 多头排列
- 收盘价 > MA5/MA10/MA20/MA60
- 5日穿10日 / 5日穿20日（均线金叉）
- 二次突破 / 缩量回踩
- 量比 > 1.5 / 缩量（量 < 前5日均量 60%）
- 创 20/30/60 日新高
- RSI 超卖 / KDJ 金叉
- 涨停

### 基本面类
- PE > 0 且 < 30 / < 50
- PB < 3 / < 5
- ROE > 10% / > 15%
- 流通市值 20-500 亿

### 量价类
- 放量上涨 / 缩量回调 / 量价配合

## 上线标准

- 某「指标组合 × 周期」胜率 ≥ 60% 且样本 ≥ 30，才进入推荐
- 单日推荐可超 3 只（供用户人为筛选，建议 TOP 5-10）
- 每只必带止损价（按周期对应幅度）

## 刷新频率

- 组合胜率排行：**每周重算一次**
- 每日选股：用当前排行最优组合，跑当日数据
