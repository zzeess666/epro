# M9 优化买入时机（企稳确认）— 开发任务指令

> 供 cursor-agent 执行。核心：回踩后不立即买，等「企稳」确认后再买，提升胜率。

## 背景

当前回踩买入"收盘<信号日收盘就买"，可能买在回调半山腰，导致胜率仅24.5%。优化：回踩后再等"企稳"信号（阳线止跌 + 不再创新低），买入点更精准。

## 目标

修改 `src/combo/combination_miner.py` 的买入逻辑，从「回踩日买入」改为「回踩 + 企稳确认后买入」。

## 买入逻辑（两步）

### 第1步：找回踩日（T+1 到 T+10，不变）
信号日 T 之后 10 个交易日内，第一个满足以下条件的日子：
- 收盘价 < 信号日收盘价（回调）
- 且 收盘价 > MA20（趋势未破）
- 且 成交量 ≤ 信号日成交量（缩量）

### 第2步：找企稳日（回踩日之后，最多再等 3 天）
回踩日之后 3 个交易日内，第一个满足以下条件的日子：
- 收盘价 > 开盘价（阳线，止跌）
- 且 最低价 ≥ 回踩日最低价（不再创新低，卖压枯竭）

### 买入与止损
- 买入价 = 企稳日收盘价
- 止损 = 买入价 × 0.92（保持 -8%）
- 持有：从企稳日起 hold_days 天
- 若回踩后 3 天内无企稳 → 放弃该信号

## 实现要点

- `_find_pullback_entry` 改为返回回踩日，再新增 `_find_stabilize_entry` 找企稳日
- 或合并为一个函数 `_find_entry`：回踩日 + 企稳日两步定位
- 大盘过滤、训练/测试切分、样本门槛、盈亏比评估逻辑保持不变
- 无未来函数（企稳日判断只用当日及之前数据）

## 验收标准

1. 重新跑挖掘，观察胜率是否提升（目标 30%+），同时期望收益不降
2. 买入价 = 企稳日收盘（不是回踩日收盘）
3. 3天无企稳的信号被放弃
4. 止损仍为 -8%
5. 盈亏比、期望收益评估不变

## 禁止事项

- ❌ 不改因子库、大盘过滤、盈亏比评估
- ❌ 不 git commit/push
- ❌ 不用未来数据
