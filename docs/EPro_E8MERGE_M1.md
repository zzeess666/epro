# EPro 尾盘观察列表页面

## 背景

用户在 EPro 上新增一个「尾盘观察」页面，每天 14:45 左右运行，扫描全市场找出满足 top3 组合的所有股票，供用户次日决策参考。

## 数据基础

- 因子数据：`factor_flag`（每日收盘后计算，基于昨日收盘价）
- 价格数据：`daily_kline`（同步新浪实时行情，含今日 O/H/L/C/PC）
- 组合数据：`combo_rank`（已挖掘的组合及胜率）
- 指数数据：`index_kline`（大盘过滤）

## Top3 组合（固定写死）

1. `box_breakout+expma_golden+gap_up`（测试胜率 68.72%，样本 1397）
2. `box_breakout+expma_golden+second_breakout`（测试胜率 67.97%，样本 1255）
3. `box_breakout+gap_up+second_breakout`（测试胜率 63.56%，样本 5647）

## 扫描逻辑

### 数据时效性说明

因子 flag 基于**昨日收盘价**计算，价格基于**今日最新行情**（新浪实时），14:45 盘中数据存在偏差是预期行为（用于观察，非精确信号）。

### 步骤

1. **大盘过滤**：读取上证/深证/科创50/创业板 指数 MA20 状态，任一指数在 MA20 上方视为多头，否则空仓
2. **获取今日价格**：读取 `daily_kline` 今日数据（含 O/H/L/C/PC）
3. **计算 gap_up**：今日开盘价 > 昨日收盘价 × 1.02（涨幅 > 2%）
4. **匹配组合因子**：从 `factor_flag` 读取昨日因子，对每只股票检查是否满足 3 个组合各自的因子条件
5. **按胜率排序输出**

### 稳定性标注

每个因子标注盘中稳定性：

| 因子 | 14:45 可用性 | 稳定性 |
|------|:-----------:|:------:|
| gap_up | ✅ 今日O vs 昨C | 高 |
| box_breakout | ⚠️ 依赖今收盘确认 | 低 |
| expma_golden | ⚠️ EMA依赖收盘价 | 低 |
| second_breakout | ⚠️ 盘中突破可能消失 | 低 |

**功能**

- 页面加载时自动请求 `/api/watchlist`
- 显示大盘过滤状态
- 3 个组合分区展示，每个分区显示满足的股票列表
- 每只股票显示：代码/名称/涨跌幅/满足的信号/稳定性标注
- 股票代码可点击查看新浪日线图

## 文件清单

1. `src/web/routes/watchlist.py` — 新增 API 路由
2. `public/index.html` — 新增「尾盘观察」Tab
3. `public/assets/css/app.css` — 复用 e8 风格
4. `src/screen/watchlist_generator.py` — 新增扫描逻辑模块

## 验收标准

1. 页面加载后显示尾盘观察列表
2. 3 个组合分区清晰
3. 每只股票显示信号和稳定性标注
4. 大盘空头时显示「空仓」状态
5. 响应时间 < 5 秒

## 技术约束

- 不新增数据库表
- 不调用麦蕊 API（使用本地因子数据 + 已有 K 线数据）
- 风格复用 M17 e8 设计系统
