# EPro — 稳健低风险 A股投研系统

基于对 E8（第一版）的理解，全新设计的 A 股选股系统。核心定位：**稳健低风险，先算风险再算收益**。

## 定位与原则

| 原则 | 说明 |
|------|------|
| 风控第一 | 最大亏损 ≤ 4% 才进入候选 |
| 回溯验证 | 胜率 < 60% 的策略不上线 |
| 宁缺毋滥 | 单日推荐 ≤ 3 只 |
| 必带止损 | 不带止损价不推荐 |

## 功能

- 下午收集数据（17:00 起同步全市场日K + 基本面）
- 回溯胜率分析
- 推荐股票（评分排序 + 理由 + 止损价）
- 基本面查询
- 次日实时跟踪 + 尾盘提醒

## 三个策略

- **A 二次突破**：首次突破30日新高 → 缩量回调不破低 → 再放量突破
- **B 缩量回踩**：上涨趋势中缩量回踩均线支撑
- **C 综合评分**：估值 + 技术形态 + 历史利润 + 资金流入 四维打分

## 技术栈

- Python 3.11 + FastAPI + SQLite/MySQL
- 数据源：麦蕊 API
- 部署：腾讯云服务器 + cron
